Emberline is a round-based tactical FPS in three.js: 5v5 against bots on the Cinder Yard map, a bomb to plant and defuse, money and a buy menu between rounds, and gunplay where stopping to aim pays.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
